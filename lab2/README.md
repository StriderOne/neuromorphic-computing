# Лабораторная работа 2. Градиентное обучение и спайковые данные

С помощью фреймворка snnTorch или SpikingJelly дообучить спайковый ResNet для классификации объектов датасета DVSGesture.

## Задание

1. Выбрать представление спайковых данных.
2. Выбрать функцию суррогатного градиента.
3. Выполнить один из двух вариантов:
   - Добавить классифицирующие слои к энкодеру ResNet и дообучить сеть в спайковом домене.
   - Обучить с нуля свёрточную сеть на этой задаче по [руководству SpikingJelly](https://spikingjelly.readthedocs.io/zh-cn/latest/tutorials/en/classify_dvsg.html).
4. Оценить качество классификации.
5. Сравнить скорость обучения для трёх разных видов суррогатных градиентов.
6. Оценить метрики: число операций MAC и AC, задержку сети в тактах T, число спайков.
7. Использовать регуляризацию по числу спайков и оценить её эффект.

## Критерии сдачи

Понимать, как работают суррогатные градиенты применительно к спайковым сетям.
